🗓️ Tkinter Calendar App

A simple and interactive Python Tkinter project that allows users to select any date and instantly get the day of the week (Monday, Tuesday, etc.).
Perfect for beginners learning Tkinter, date handling, and GUI development.

no need of any module or library just tkinter and some math calculations 

🚀 Features

✔️ Built with Tkinter (Python’s default GUI library)

✔️ User selects Day / Month / Year

✔️ App instantly shows which weekday that date falls on

✔️ Clean and simple GUI

✔️ Lightweight & beginner-friendly code

🛠️ Tech Stack

Python 

Tkinter
